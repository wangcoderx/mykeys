# 冒泡排序交互可视化：设计规格

## 项目与目标

这是一个用于学习冒泡排序的单页网页 Demo。核心不是自动播放一段看完即逝的动画，而是让用户掌握节奏：输入任意数字序列，选择升序或降序，然后用「下一步」逐次查看比较与交换；同时可以后退复盘、自动播放、暂停、重置。页面必须在无需服务器、无需联网的前提下双击 HTML 直接运行。目标受众是第一次理解排序算法的学生，也兼顾教师投屏演示和开发者快速复习。

## 核心内容与交互

- 输入区：接受空格、英文逗号或中文逗号分隔的有限数字，支持负数与小数；限制为 2–12 个元素，给出明确的就地错误提示。
- 排序方向：升序 / 降序切换。切换后重新生成步骤并回到起点。
- 可视化舞台：以高度柱和数字卡的同一组元素表达数组；元素位置交换必须有物理重量感的位移动画。当前比较的两个元素用暖色聚焦，确定交换时用第二强调色标示，已经就位的尾部/头部区间标为完成态。
- 步骤控制：上一步、下一步、自动播放/暂停、重置；键盘左右方向键也能逐步操作。任何一步都应可逆、可直接恢复为唯一状态，不依赖长链 setTimeout。
- 教学解释：清楚显示第几轮、当前比较的索引和值、是否需要交换，以及一句贴近当下动作的中文解释。显示比较次数与交换次数。
- 进度：使用真实算法步骤计算进度，不伪造数据。结束时给出完成反馈，并保留最终数组。
- 边界：已在第一步时禁用「上一步」，完成时禁用「下一步」；自动播放时输入与方向切换应安全重置或暂停。

## 视觉与情感

网页在 1 米笔记本距离和教室投屏场景下都应清楚。气质是「有教学亲和力，但不幼稚」：暖色纸张感背景、深墨文字、单一主强调色，再配一个用于交换动作的警示色。避免紫色万能渐变、通用 Dashboard 卡片堆叠、emoji 图标和无意义统计装饰。标题允许带一点编辑设计感，算法状态与数字使用等宽字，形成内容与功能的双字体层级。动画采用 expo-out / spring 语感，比较前有短停顿，交换动作清楚但不拖沓。

## 输出格式与尺寸

三套视觉探索均为纯 HTML/CSS/JavaScript 单文件，放在 `bubble-sort-visualizer/design-demos/` 下；响应式覆盖 1440×900、768×1024 与 375×667。最终项目入口为 `bubble-sort-visualizer/index.html`，无需构建工具或外部 CDN。页面应支持 `prefers-reduced-motion`，并具备基础可访问性：表单标签、按钮状态、键盘操作、状态区域 aria-live、足够的颜色对比度。

## 三套探索的共同功能验收

三版必须真正实现相同的排序能力，而非静态外观：自定义序列、升降序、前后步进、自动播放、暂停、重置、输入校验、比较/交换/完成态、轮次与统计信息。每版使用原生 JavaScript 预计算纯状态步骤，渲染任一步都只依赖当前步骤索引。最终推荐版需要通过浏览器控制台错误检查与至少一条完整点击路径验证。
